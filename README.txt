SHRUTI MEMORY WEBSITE

This is a separate, ready-to-upload website for Shruti.
All five photos are already included in assets/photos/ with the exact filenames used by index.html.

IMPORTANT:
- Upload the CONTENTS of this folder to a NEW GitHub repository named shruti-memories.
- Keep index.html, style.css, script.js, and the assets folder together at the repository root.
- Do not upload this into the existing harinee-birthday repository.
- Enable GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
- The new URL will be https://YOUR-USERNAME.github.io/shruti-memories/
